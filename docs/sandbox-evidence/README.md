# Sandbox evidence

No authenticated Airwallex call has been made from this project.

When a call is authorised, add a sanitised record here with:

- UTC timestamp
- endpoint and API version/headers (no secrets)
- request ID and correlation ID
- response status and a redacted response summary
- before/after balance evidence, if relevant
- the feature the observation verifies

Never commit raw banking responses, tokens, full account numbers, or personal
data. A fixture is not evidence of provider capability.
